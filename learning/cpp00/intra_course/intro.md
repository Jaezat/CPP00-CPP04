# Namespace

- Group together symbols and functions.
- If two or more things have the same name = conflit.
- Uses to resolve conflits when two or more things have the same name. 

```
using namespace std;

namespace namespace1 
{
    int age = 25;
    string name = "Flor"
}

namespace namespace2 
{
    int age = 98;
    string name = "Per"
}
```
