# I. Floating points numbers

- Accuracy -> how close a measurement is to the true value.
- Precision -> how much info i have about the quantity.
- Integers lack precision: Integers are unable to keep track of the fractional part, so the information that I had a slightly bigger number than 4 (namely, 5) is lost in the process.
- Diferente de floating points: es muy dificil con floating points tener una precision exacta. Por ejemplo va a ser casi imposible hacer un cubo y armar las esquinas con floating numbers.
